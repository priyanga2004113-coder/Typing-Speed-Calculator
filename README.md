# Typing-Speed-Calculator

A simple and responsive Typing Speed Test application built using HTML, CSS, and JavaScript.  
This project helps users measure their typing speed and accuracy in a clean and user-friendly interface.

## Features

- Real-time typing speed calculation (Words Per Minute)
- Accuracy percentage calculation
- Progress bar to track typing completion
- Responsive design for mobile and desktop
- Simple and clean user interface
  

## Technologies Used

- HTML5  
- CSS3  
- JavaScript 



## How to Use

1. Open the application in a web browser  
2. Click on the "Start Typing Test" button  
3. Begin typing the given text  
4. After completion, view your typing speed and accuracy
